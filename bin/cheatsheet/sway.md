# Sway Cheatsheet

> **`$mod` = `Super` (Windows key)**

## Applications
| Key | Action |
|-----|--------|
| `$mod + Return` | terminal (alacritty) |
| `$mod + r` | Chrome |
| `$mod + w` | Firefox |
| `$mod + b` | Chromium |
| `$mod + t` | Telegram |
| `$mod + u` | Discord |
| `$mod + e` | Thunar |
| `$mod + n` | Obsidian |
| `$mod + y` | VS Code |
| `$mod + m` | Spotify |
| `$mod + v` | Caido |
| `$mod + p` | Monitor setup |
| `$mod + Space` | Ulauncher |
| `$mod + Shift + x` | CopyQ clipboard |
| `$mod + Shift + d` | Toggle DND |
| `$mod + /` | This cheatsheet |

## Window Management
| Key | Action |
|-----|--------|
| `$mod + q` | kill window |
| `$mod + Shift + f` | fullscreen toggle |
| `$mod + Shift + Space` | floating toggle |
| `$mod + Shift + a` | focus parent |
| `$mod + Tab` | focus next |
| `$mod + Shift + Tab` | focus prev |
| `$mod + LMB drag` | move floating window |
| `$mod + RMB drag` | resize floating window |

## Focus & Movement
| Key | Action |
|-----|--------|
| `$mod + ←↓↑→` | focus direction |
| `$mod + Shift + ←↓↑→` | move window direction |
| `$mod + Shift + h` | split horizontal |
| `$mod + Shift + v` | split vertical |

## Layouts
| Key | Action |
|-----|--------|
| `$mod + Shift + q` | stacking layout |
| `$mod + Shift + w` | tabbed layout |
| `$mod + Shift + t` | toggle split |

## Workspaces
| Key | Action |
|-----|--------|
| `$mod + 1-0` | switch to workspace 1-10 |
| `$mod + Shift + 1-0` | move window to workspace 1-10 |
| `$mod + Ctrl + ←↓↑→` | move workspace to monitor |

## Resize Mode
| Key | Action |
|-----|--------|
| `$mod + Shift + r` | enter resize mode |
| `←↓↑→` | resize in mode |
| `Return / Escape` | exit resize mode |

## Screenshots & Recording
| Key | Action |
|-----|--------|
| `Print` | screenshot active window |
| `Shift + Print` | screenshot region |
| `$mod + Shift + S` | screenshot region |

## System Controls
| Key | Action |
|-----|--------|
| `XF86AudioRaiseVolume` | volume up |
| `XF86AudioLowerVolume` | volume down |
| `XF86AudioMute` | mute toggle |
| `XF86AudioMicMute` | mic mute toggle |
| `XF86MonBrightnessUp/Down` | screen brightness |
| `XF86KbdBrightnessUp/Down` | keyboard backlight |
| `XF86AudioPlay/Pause` | play / pause |
| `XF86AudioNext/Prev` | next / prev track |

## ROG Specific
| Key | Action |
|-----|--------|
| `$mod + F12` | toggle airplane mode |
| `XF86TouchpadToggle` | toggle touchpad |
| `XF86Launch1` (M1) | cycle power modes |
| `XF86Launch3` (M3) | next aura effect |
| `XF86Launch4` (M4) | prev aura effect |

## Sway Control
| Key | Action |
|-----|--------|
| `$mod + Shift + c` | reload config |
| `$mod + Shift + e` | exit sway prompt |
| `$mod + Shift + l` | lock screen |
